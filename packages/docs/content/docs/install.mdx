# Install

There are three ways to run NoatinWork:

- desktop app for macOS
- web app hosted by the CLI, which you can install like a phone app (a PWA)
- VS Code extension

## Prerequisite

Install [OpenCode](https://opencode.ai) first — NoatinWork runs on top of it.

## Web + PWA

```bash
curl -fsSL https://raw.githubusercontent.com/ccccczl01/noatinwork/main/scripts/install.sh | bash
noatinwork --ui-password be-creative-here
```

Open the URL the CLI prints (usually `http://localhost:3000`). You should see the NoatinWork session list. To keep it handy, use your browser's "Install" option in the address bar to add it as an app.

## Desktop

Download the latest desktop build from the GitHub releases page or the NoatinWork download page. Open it and sign into your usual OpenCode workflow.

## VS Code

Install from the VS Code Marketplace and sign into your usual OpenCode workflow. The NoatinWork view then opens in the sidebar.
